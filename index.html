Política de Privacidade

Última atualização: novembro de 2026.

1. Uso dos Serviços de API do YouTube

O Autopost utiliza os Serviços de API do YouTube (YouTube Data API v3) exclusivamente para verificar o canal do próprio administrador (channels.list) e enviar/agendar vídeos originais (videos.insert). Ao utilizar esta ferramenta, o utilizador concorda com a Política de Privacidade do Google e com os Termos de Serviço do YouTube.

2. Armazenamento e Partilha de Dados

A ferramenta é privada, sem registo público e sem utilizadores externos. Não são recolhidos, armazenados externamente nem partilhados dados de terceiros. Os tokens OAuth ficam armazenados apenas localmente na máquina do proprietário.

3. Revogação de Acesso e Eliminação de Dados

O acesso concedido à conta Google pode ser revogado a qualquer momento através da página de definições de segurança do Google, além da eliminação local do ficheiro de credenciais. Para contacto ou pedidos de eliminação: thiagolaurinosilva16@gmail.com.
